# Tres Comas — Invariants

**Last updated:** 2026-11-13. Source: `v1_spec.md` §Invariants.

These nine rules hold in every release. A change that breaks one needs a recorded decision in `design_decisions.md` **first**. Before changing code on an invariant's path, read its row and run its tests.

Columns: **Owner** is the code that upholds the rule (planned paths until built). **Guard** is what catches a break: a test, the pre-tool hook (`.claude/hooks/pre_guard.py`), CI, or "review only".

| ID | Rule | Owner (planned) | Guard |
| --- | --- | --- | --- |
| INV-1 | The app never holds broker credentials and never calls a broker or account-aggregator API. | `connections/` is the only outbound HTTP module; no provider of kind `broker` or `aggregator` exists. | Hook denies broker/aggregator hosts in code (`BROKER_HOST_RE`). **Test:** `test_inv1_no_broker_connection_kinds` (service ValueError + DB CHECK). |
| INV-2 | Transactions are the source of truth. Positions are always derived and never edited directly. | `services/ledger.py` (sole writer; refuses changes that would go negative, D-20), `services/positions.py` (derivation, D-19); DB triggers `transactions_no_delete` / `transactions_no_update` (migration 0001, D-16). | **Tests:** `test_inv2_transaction_delete_is_refused`, `test_inv2_transaction_amount_update_is_refused`, `test_inv2_voiding_once_is_allowed_twice_is_refused`, `test_inv2_void_and_replace_pair`, `test_inv2_no_positions_table`, `test_inv2_positions_rebuild_from_transactions`, `test_inv2_ledger_is_sole_transaction_writer` (scans `app/` for `Transaction(` outside `services/ledger.py`). `test_inv2_no_position_write_endpoint`. |
| INV-3 | Every secret lives app-side in the production `.env`, which is never committed. No client, Claude included, receives a secret. | `deploy/.env.production.example` (names only); registry stores `.env` key **names**. | Hook denies agent edits to any `.env*` except examples; `.gitignore`. **Tests:** `test_inv3_password_hash_never_returned`, `test_auth_default_deny_every_route` (D-23), `test_inv3_registry_never_returns_secret_values`, `test_inv3_secret_never_logged_header` / `_query_param`, `test_inv3_connections_api_never_returns_secret`. |
| INV-4 | Market-data calls send tickers only: never quantities, values, account names or cost basis. | `app/connections/client.call` scope check per kind (D-26). | **Test:** `test_inv4_market_data_payload_is_tickers_only` (D-26). `outbound_logs` viewable in the PWA Connections screen. |
| INV-5 | The app never places a trade. It records trades made elsewhere. | No order/trade-placement code path exists. | Hook denies broker hosts; review. |
| INV-6 | External clients cannot write to the ledger. They can only create proposals that Musa confirms inside the app. | `mcp_server/` imports `services/proposals.create` only; confirm is a session-authenticated UI route. | **Test:** `test_inv6_api_cannot_set_source_or_proposal` (REST bodies forbid `source`, `proposal_id`, `import_batch_id`, `natural_key`). Planned: `test_inv6_mcp_has_no_write_tools`, `test_inv6_token_scopes_exclude_write`. |
| INV-7 | Every outbound integration is a row in the connection registry, can be switched off there, and every call it makes is logged. | `app/connections/client.call` and `registry.py` (D-26–D-28). | **Tests:** `test_inv7_disabled_connection_makes_no_call`, `test_inv7_every_call_logged`, `test_inv7_new_connection_disabled`. Hook asks on raw HTTP imports outside `connections/`. |
| INV-8 | No real account numbers are stored. Accounts carry nicknames. | `Account` model (no number column); importers drop account-number columns. | **Tests:** `test_inv8_accounts_have_no_account_number_column`, `test_inv8_api_rejects_account_number`. Planned: `test_inv8_importer_strips_account_numbers`. |
| INV-9 | Money and quantities are stored as decimals with an explicit currency, never as floats. | `app/models/types.DecimalText` (D-15); currency CHECKs on every money table; `services/ledger._to_decimal` (T3); Pydantic schemas take and emit strings (`app/schemas`, `dec_str`). | Hook asks on `Float`/`float(` in `backend/app/models` and `services`. **Tests:** `tests/test_types.py` (`test_inv9_*`: exact round-trip, plain notation, float/bool/NaN refused), `test_inv9_no_float_or_numeric_columns`, `test_inv9_money_tables_have_currency`, `test_inv9_ledger_rejects_float` / `_bool` / `_non_finite`, `test_inv9_api_rejects_json_numbers`. Frontend: `src/lib/format.js` rounds decimal strings without `Number`. |

**Naming:** invariant tests are named `test_inv<N>_<what>` so this table can be checked with `grep -r "def test_inv" backend/tests`.
