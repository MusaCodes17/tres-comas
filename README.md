# Tres Comas

A self-hosted ledger of every investment account, entered by hand or by CSV, that shows true exposure across accounts once ETFs are unpacked. No broker connection of any kind. Part of the Son of Anton family of tools.

**Status:** pre-build — docs spine and agent guardrails only. Build starts at T1 (`docs/roadmap.md`).
